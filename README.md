# AikoShield

Partage ton écran sans rien dévoiler. AikoShield lit l'écran en continu (sur ton Mac, rien n'est envoyé ni enregistré) et recouvre automatiquement :

- **E-mails et téléphones** : adresses, numéros français et internationaux ;
- **Banque et paiements** : IBAN, numéros de carte, montants sur les pages bancaires ;
- **Mots de passe et codes** : codes de vérification, clés d'API, `MOT_DE_PASSE=…`, gestionnaires de mots de passe ;
- **Notifications** : les bannières qui surgissent en plein partage.

Tu peux aussi choisir des apps à cacher en entier (Messages, WhatsApp, Mail…).

## Utilisation

- **⌃ ⌥ S** active / coupe le bouclier (raccourci modifiable).
- L'icône bouclier de la barre des menus devient bleue quand il est actif.
- *Ouvrir la page de test* montre de fausses données pour vérifier que tout se couvre.

## Bon à savoir

- Partage **l'écran entier** (Zoom, Meet, Teams, Discord, OBS…). Si tu ne partages qu'une fenêtre, les masques n'apparaissent pas dans le partage.
- Une info qui apparaît ou défile peut rester visible une fraction de seconde avant d'être couverte.
- macOS demande l'autorisation « Enregistrement de l'écran ». Après une mise à jour de l'appli, il faut parfois la redonner.

## Installation (Mac)

Télécharge `AikoShield-Mac.zip` dans les versions, ou compile toi-même : double-clic sur `macos/Installer AikoShield.command` (outils de développement Apple requis).
